# PR-05: 記事からの次の一手

対象は US-07 / AC-07、US-08 / AC-08、US-18 / AC-18。記事の主カテゴリがGitHub・収益化・旅行の場合に、カードの確認欄とコピーボタンを表示する。

## 使い方と情報の境界

「指示を確認」を開いて内容を読み、使う記事のボタンだけを押す。コピーされるのは固定テンプレートと、その記事の公開タイトル・URL・取得元・説明。GitHubの場合だけ公開ライセンス属性とアーカイブ状態も含む。欠損値は未確認、デモ記事はデモと明示する。

コピーはクリップボードへ書くだけで、CodexやChatGPTを開かず、コード実行・投稿・購入・予約・アカウント操作もしない。送信先のツールへの貼り付けは利用者が選ぶ。重み・保存・既読・他の記事・ローカルストレージは指示に含めない。履歴をまとめて送信する機能はない。

ブラウザーの権限やAPI非対応でコピーできなければ失敗を通知する。必要なら確認欄のテキストを選択してコピーする。コピー成功は外部ツールでの調査・実行成功を意味しない。

## テンプレート

- **GitHub**: 0〜10分の原典調査、10〜20分の依存コード・ライセンス・費用・権限・通信・資格情報送信の確認、20〜30分の最小実験計画。安全確認が終わらなければ調査で止める。実行には利用者の明示的な承認を求め、隔離環境とダミーデータを使う。未実行を成功と扱わない。
- **収益仮説**: 全カードに「収益性未検証」と着想元リンクを表示する。顧客・課題・競合・導入費・継続費・ライセンス・規約・実証方法を、確認済み事実・仮説・未確認に分ける。次の検証を1つ選び、成功・中止条件を決める。記事やOSSそのものは需要や利益の証拠ではない。
- **旅行**: 訪問候補日の営業情報と往復交通の確認から始める。施設・自治体・交通機関などの原典URLと確認日を求め、見頃・料金・営業時間を創作しない。詳細な自宅住所や位置履歴は求めず、予約・購入を実行しない。

## 制限と互換性

固定指示は調査の補助であり、外部ツールの従順性・安全性を保証しない。第三者の見出し・説明はJSONのデータとして囲み、命令として扱わないよう明記する。HTMLは画面上でエスケープする。利用者は貼り付ける前と、実行を承認する前に内容を確認する。

公開フィードの形式・収集・推薦順・保存データは変更しない。旧形式の記事にも表示可能。コピーは有料APIやアプリ間の自動入力を使わない。Android実機のクリップボード権限とPWA更新は別途確認が必要。

Service Workerの静的キャッシュをv6に更新し、既存の正常フィードの引き継ぎと他アプリのキャッシュ保護を維持する。
