# PR-06: モバイル操作とアクセシビリティ

対象は US-05 / AC-05、US-06 / AC-06、US-17 / AC-17。既存カテゴリの重み・保存・検索を維持し、テーマ追加や非表示機能は含めない。

## 操作

- 最初のTabで「記事一覧へ移動」を表示し、Enterでカテゴリナビゲーションと導入部分を飛ばせる。
- リンク・ボタン・検索・選択欄・折りたたみ・指示全文にキーボードフォーカスの輪郭を表示する。
- 保存とカテゴリの選択状態は`aria-pressed`で伝える。保存・モバイルカテゴリ切替でDOMを作り直しても同じボタンにフォーカスを保つ。保存一覧から最後のカードを外した場合は一覧見出しへ移す。
- 記事全文を毎回ライブ通知せず、表示件数と空結果からの解除手段を短いステータスで伝える。読み込み失敗時は記事がないことと取得状況の確認を案内する。
- 設定ダイアログ内のTab / Shift+Tabは先頭と末尾を循環し、Escapeまたは完了・閉じるで戻る。スライダーは矢印キー・Home・Endで変更でき、数字と「最優先」等の意味を属性に反映する。
- 主なボタン・選択欄・スライダーは高さ44px以上、設定と保存のアイコンボタンは幅も44px以上。指示全文はTabで移動してスクロールできる。

重み・保存・既読は従来どおり同じブラウザーのlocalStorageで維持する。同期や公開JSONへの書き戻しは行わない。ブラウザーの保存領域が利用できない場合の永続化は保証しない。

## 検証と限界

`python tests/accessibility_smoke.py`で360 / 390 / 430 / 1280pxの実ブラウザーを操作する。スキップ、検索解除、保存後のフォーカス、カテゴリ状態、指示全文のPageDownスクロール、モーダルの循環・復帰、スライダー値・保存設定の再読み込み、原典の別タブから戻った後の保存、操作領域と横はみ出しを検証する。スマホ幅ではタッチもエミュレートする。

コントラストは検索のプレースホルダー・選択欄の実計算色と、代表的な記事文字（日時・説明・出典・スコア・原典・次の一手・未検証表示）を確認する。記事のグラデーションは実際の合成背景より明るい`rgb(54,45,89)`を保守的な背景として使い、通常文字の4.5:1以上を検証する。補助文字と日時は必要な色だけ調整する。

既存の`python tests/browser_smoke.py`も実行し、フィルター・重みでの順位変化・コピー・取得状況・実Service Workerによるオフライン復元を別途確認する。

これらは全要素のWCAG適合認証ではない。ブラウザー上のロール・ラベル・状態属性は自動確認するが、TalkBack / VoiceOver / NVDAによる実際の読み上げ、Android実機のタッチとPWA更新は未検証。変更後のPagesは公開後に別途確認する。

Service Workerの静的キャッシュはv7。フィード形式・収集・推薦ロジック・既存保存データは変更しない。
